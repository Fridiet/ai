# 합산 묶음 포장량 계산 (2026-09-12)

## 구현

`parse_inventory_quantity`에서 중량/부피 단위 뒤에 붙은 명시적 포장 구성을
처리한다. 예: `85g*4+2입`, `85g4+2입`, `85g×(4+2)입` → 510g.
곱셈 기호가 OCR에서 생략된 경우에도 뒤의 `4+2입` 포장 구성은 사용한다.
두 개의 양의 정수, 명시적 포장 단위, 닫힌 괄호, 문자열 끝이라는 제한을 둔다.
식 평가(eval)는 사용하지 않는다.

`85g*4+2`처럼 포장 단위 없는 표기, 뒤에 붙은 행사 문구, 모순된 괄호,
소수·음수·0·과도한 개수는 확인 대상으로 남긴다. 앞에 붙은 `1+1 행사`만으로
포장량을 곱하지 않는다. 두 묶음 구매는 별도 구매 개수와 곱해1020g이 된다.

## 실제 개발 이미지 검증

초안의 `플레인요거트`와 정확 일치하지 않는다. 전체 항목이 해결됐다고 보지 않는다.

# 열 위치 기반 숫자 재인식 실험

2026-09-12, 이전 재인식 결과를 확인한 후 아직 시험하지 않은 IMG00238/IMG00240의
단가·수량·금액 영역을 읽었다. 보조960의 검증된 열 기준점과 행 박스로 원본
이미지를 잘랐다. 원본 SHA와 development 분할을 검증했고 frozen 자료는 사용하지 않았다.

| 대상 | 0 여백 단가/수량/금액 | 각 confidence |
|---|---|---|
| 감자칩 | 890 / 1 / 890 | .906 / .990 / .988 |
| 드레싱 | 3780 / 1 / 3780 | .999 / .973 / .997 |
| 고등어 | 3580 / 1 / 3580 | .993 / .986 / .874 |

세 행 모두 기존 원본 OCR은 가격 하나를 놓쳤지만 숫자 crop에서 세 필드를 읽었다.
결과는 앞서 이미지로 작성한 개발 정답 수량1과 일치한다.
그러나 세로 여백15%에서는 감자칩 금액89, 드레싱 수량빈칸, 고등어 수량i가 나왔다.
따라서 여백 확대 또는 confidence 하나만으로 일괄 채택할 수 없다.

재인식 호출 시간: IMG00238 12crop .492초, IMG00240 6crop .158초.
이는 모델 초기화·기본/보조 검출·API 전체 시간을 제외한 수치다.

이 방식은 이전 헤더 글자 폭만 사용한 수량crop과 다르다. 합쳐진 헤더도
검증된 본문 열 위치로 보정해 숫자영역 전체를 읽는다.
현재는 `scripts.experiment_calibrated_numeric_crops.py`의 진단 코드이며
운영 API나 구매 개수 출력은 바꾸지 않았다.

다음 검증은 더 많은 미확정 행 및 이미 맞는 행을 대조군으로 포함해,
세 숫자의 형식·산식·기존 가격·행 매핑을 동시에 검사하고 잘못된 보정률을 측정해야 한다.
이번 세 행 성공은 전체 자동 등록률의 개선을 입증하지 않는다.

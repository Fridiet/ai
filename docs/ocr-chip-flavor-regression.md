# 감자칩 맛 표기 보정 검증

2026-09-12 작업 기록. AI 코드만 수정했으며 실행 중인 8000 서버에는 아직 적용하지 않았다.

## 변경

`감자침` 뒤에 명시적인 맛 이름이 있는 경우에만 `감자칩`으로 보정한다. 사워크림 부분 일치가 상품 전체의 이름을 대체하지 않도록 기존 상품 종류 우선 경로를 사용한다. 단독 `감자침`, 두 글자 이상 손상된 `김자침사워크림`, 뒤에 소스·우유가 붙은 상품은 이 규칙으로 확정하지 않는다.

## 검증

- 전체 테스트: 546개 통과.
- 개발용 이미지 21장의 기존 OCR 캐시 재평가: 이름 정답 52/74 → 54/74, 잘못 확정된 이름 4건 → 2건.
- 이름과 구매 수량 동시 정답: 29/74로 동일. 보정된 두 행의 수량은 여전히 확인이 필요하다.
- 구매 수량 정답: 51/91로 동일, 잘못 확정된 구매 수량 0건.

이 평가는 사람이 확정하지 않은 보조 검수 초안이며 개선에 사용한 개발 데이터다. 독립 평가 정확도 또는 전체 등록 준비율이 아니다. 보관 위치와 날짜 정확도도 포함하지 않는다. 미사용 평가 이미지 30장은 이번 작업에서 열람하거나 학습에 사용하지 않았다. 이번 변경은 OCR 엔진 처리 시간을 측정하지 않았다.

## 남은 문제

수량 누락이 자동 등록을 제한한다. 남은 손상 상품명과 포괄적인 모델 분류도 별도로 개선해야 한다. 평가용 정답 확충, 독립 평가, 실행 서버 적용 후 통합 검증까지 완료해야 목표 달성을 판단할 수 있다.

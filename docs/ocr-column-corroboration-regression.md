# 수량 열 교차 검증 실험

2026-09-12. AI 폴더 변경이며 실행 서버 적용 및 원격 푸시는 하지 않았다.

## 변경과 안전 조건

단가·수량·금액이라는 명시적 제목이 있지만 OCR 제목 상자가 합쳐진 경우, 기존에는 완전히 인식된 산술 일치 상품 행 두 개가 필요했다. 이제 완전히 인식된 행 하나와 같은 가격 열 위치의 다른 두 가격 쌍이 함께 있을 때도 열 위치를 검증한다. 가격 신뢰도 0.9 이상, 정수 배수, 위치 오차 제한은 유지한다. 제목 없는 영수증에는 적용하지 않으며 수량 열에서 다른 문자나 숫자가 관측되면 덮어쓰지 않는다. 복원된 수량은 기존 `RECONSTRUCTED_PRICE_COLUMNS` 출처와 확인 안내를 유지한다.

## 검증 결과

- 전체 테스트 548개 통과.
- 신규 개발용 21장: 이름 54/74, 구매 수량 51/91, 이름·수량 동시 정답 29/74. 변경 전과 동일.
- 기존 개발용 98장: 구매 수량 131/311 → 132/311. 이름·수량 동시 정답 71/303으로 동일. 잘못 확정된 수량 0건 유지.
- 바뀐 행은 IMG00088.png의 `롯덴칠성델몬트망고 4,990 9,980`. 구매 수량 2를 복원했지만 재료명은 여전히 포괄적인 `음료`이므로 등록 준비 완료로 계산하지 않는다.
- 결과 파일: `output/receipt_readiness/after-corroborated-columns.json`, `output/new_receipts/evaluation.json`.

기존 데이터는 학습/개선에 사용된 개발 자료이고 신규 정답도 보조 검수 초안이다. 독립 정확도로 해석하지 않는다. 미사용 평가 30장은 열람하거나 학습에 사용하지 않았다. OCR 재실행이 아닌 캐시 후처리 평가로 처리 시간 개선도 주장하지 않는다.

## 다음 판단

신규 영수증에서는 수량 자체가 감지되지 않거나 제목 및 가격의 신뢰도가 부족해 이 보정이 적용되지 않았다. 근거 없이 수량을 1로 채우거나 가격 숫자를 수정하지 않는다. 다음 개선은 수량 누락 영역의 영상 인식과 실제 지연 시간을 함께 비교해야 한다.

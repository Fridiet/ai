# 낮은 신뢰도 수량의 가격 열 교차 검증

## 확인된 원인

개발 IMG00059 밀가루 행의 수량 `1`은 confidence 약 0.305로 검출되어
일반 행 구성에서 제거됐다. 단가/금액 `3,300`은 각각 약 0.998/0.997이고
라벨이 있는 단가·수량·금액 열에 정렬되어 있었지만, 기존 복구 함수는
수량 칸의 어떤 글자도 허용하지 않아 일치하는 증거까지 차단했다.

## 변경

`receipt_columns.reconstruct_missing_count`에서 다음 조건을 모두 만족하면
검출된 수량을 가격으로 교차 검증한다.

- 명시적 열 헤더 또는 기존 검증을 통과한 열 기준 위치가 있다.
- 단가와 금액은 각 가격 열에 하나씩 있으며 각각 confidence 0.9 이상이다.
- 나눗셈 결과가 1~99의 정수다.
- 수량 칸의 검출은 하나뿐이며 정확한 정수 표기이고 산식 결과와 일치한다.

모순된 숫자, 기호, 음수, 소수 표기, 중복 검출은 거부한다.
숫자가 없는 경우의 기존 가격 기반 복구 조건은 유지한다.
출처는 `RECONSTRUCTED_PRICE_COLUMNS`로 유지하며 기존 확인 안내도 유지한다.
이 작업은 OCR 모델 재호출이나 이미지 변형을 추가하지 않는다.

## 검증 (2026-09-12)

| 개발 평가 | 이전 | 이후 |
|---|---:|---:|
| 새 23장, 기본 OCR 구매 개수 정답 /119 | 69 | 71 |
| 새 23장, 보조960 포함 구매 개수 정답 /119 | 80 | 81 |
| 새 23장, 보조960 포함 이름+개수 정답 /100 | 57 | 58 |
| 새 23장, 보조960 포함 구매 개수 증거가 있는 총량 정답 /23 | 11 | 12 |
| 기존 98장 구매 개수 정답 /311 | 137 | 141 |
| 기존 98장 이름+개수 정답 /303 | 73 | 74 |

기존 98장에서 변경된 구매 수량 네 건은 모두 미확정→초안 정답과 일치였다.
두 평가 모두 잘못 확정된 구매 개수는 0 유지. 재료명 및 분류 결과는 불변이다.
전체 pytest 613개 통과. 실시간 API 지연은 이번 작업에서 재측정하지 않았다.

평가 자료는 개발용 초안이며 독립 일반화 정확도가 아니다.
기존 98장은 학습/개발과의 중복 가능성이 있어 회귀 확인용으로만 사용한다.
확인 안내가 남는 복구 값이므로 이름+개수 정답 수를 무확인 자동 등록 수로 해석하지 않는다.

`output/receipt_readiness/after-count-corroboration.json`.

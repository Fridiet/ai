# OCR 작업 마무리 현황 — 2026-09-12

사용자 요청에 따라 추가 개선 범위를 넓히지 않고 현재 검증 버전을 정리한다. 전체 자동 등록 목표를 달성했다는 선언은 아니다.

## 현재 적용과 검증

- 로컬 AI 서버 8000에 최신 보정 반영. OpenAPI HTTP 200 확인.
- 사전 단독 기본 환경의 자동 테스트 793개 통과. 학습 분류기 활성 경로는 개발 자료 재생 및 실제 HTTP로 별도 확인.
- 선택된 영수증 6장 HTTP 의미 검증 통과: `output/receipt_readiness/http_semantics_8000.json`.
- 확인 항목: 백오이 5개, 감자칩 110g, 사워크림 오분류 방지, 반복 또띠아 구매 보존, 쿠폰 제외, 물의 포장 총부피, 디너롤 72개, 체다치즈 907g. 모든 행이 정확하다는 검증은 아니다.
- 불확실한 식품은 원문과 함께 확인 후보로 유지. 포장 개수만 있고 구매 개수가 없으면 수량 확인 경고를 유지한다.

## 개발용 진단 결과

### 최신 HTTP 시간 측정

동일한 개발 영수증 6장을 2회씩 순차 요청한 12건이 모두 HTTP 200으로 완료됐다. 이미지별 두 응답의 전체 JSON 해시도 모두 동일했다. 기록: `output/receipt_readiness/api_handoff_20260912.json`.

두 번째 회차 6건의 지연은 약 4.40~9.46초, 중앙값 6.61초다. 서버 모델이 이미 로드된 상태의 로컬 AI 직접 요청이며 최초 실행·동시 사용자·프론트→백엔드 경유 시간은 측정하지 않았다. 작은 선택 표본이므로 일반적인 지연 보장이나 전체 정확도 증거로 사용하지 않는다.

29장 혼합 재생에서 재료명 116/136, 구매 개수 118/160, 이름·개수 동시 일치 92/136. 총수량 일치 32/50이며 구매 개수 근거까지 요구하면 28/50이다.

명칭 정답 미확정 24행은 이름 평가 분모에서 제외했다. 반복 개선에 사용한 개발 자료와 보조 검수 초안이므로 독립 정확도나 전체 완료율로 해석하지 않는다. 최초 OCR은 캐시, 헤더·숫자 셀은 실제 재인식을 결합한 결과로 전체 HTTP 지연 측정도 아니다. 동결 평가 30장은 이 작업에서 최종 평가하지 않았다.

## 남은 한계

### 자동 등록과 인식 성공의 차이

최신 개발 보고서의 행별 결과를 다시 집계했다. 이름·개수가 모두 맞은 92행 중 73행에는 추가 확인 경고가 있고, 해당 경고가 없는 것은 19행이다. 따라서 92/136(67.6%)은 자동 등록 완료율이 아니다. 19/136(14.0%)도 소비기한 입력과 일반 보관 제안 등을 제외한 제한적인 무경고 지표이며 실제 사용자 수정률은 아니다.

정답 이름·개수 라벨이 있는 136행의 나머지 44행(32.4%)은 이름 또는 개수 수정이 필요한 개발 진단 사례다. 내역은 수량 24, 분류 보류 16, 잘못된 이름 3, OCR 또는 정렬 실패 1이다. 명칭 라벨 미확정 24행은 여기에 포함하지 않는다.

정확한 92행의 경고는 보관 방식 확인 53, 포장 내용량 확인 37, 금액으로 구매 개수 복원 23, 보조 OCR 구매 개수 확인 12, 숫자 셀 구매 개수 확인 2다. 한 행에 여러 경고가 겹치므로 합산하면 안 된다. 전체 식품 160행 중 분석 상품에 대응되지 않은 행은 2개지만, 근사 문자열 정렬 결과라 실제 이미지 OCR 누락률로 확정할 수 없다.

다음 개선의 우선순위는 수량 근거와 보관·포장 확인 부담이다. 지표를 높이려고 경고만 제거하거나 알 수 없는 포장량·소비기한을 추정 확정하지 않는다. 사용자 화면에서 실제 수정 여부를 측정하는 작업은 프론트/백엔드 변경 승인이 필요하다.

- 손상·생략된 상품명과 불명확한 가공 형태는 확인이 필요하다.
- 이름이 반환된 항목도 포장 용량·구매 개수·보관 위치 경고가 있을 수 있다. 확인 후보 개수만으로 자동 등록률을 계산하지 않는다.
- 보관 방식은 제품 표시 확인이 우선이며, 일반 보관 규칙이 실제 소비기한을 보증하지 않는다.
- 전체 독립 평가, 사용자 수정 필요율 및 다양한 사진의 반복 지연 측정은 남아 있다. 개발용 소수 이미지의 시간 측정을 일반적인 응답 시간으로 보장하지 않는다.

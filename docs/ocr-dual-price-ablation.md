# 보조 OCR 가격 복구 허용 실험 — 채택하지 않음

2026-09-12 개발25장 전체에 `scripts.experiment_secondary_price_agreement`를 실행했다.
현재 배제하는 보조 `RECONSTRUCTED_PRICE_COLUMNS`를 원본의 두 가격도 일치할 때
허용하는 오프라인 실험이다. 이름/위치/중복행 배제 및 모순된 숫자 거부는 유지했다.
출처는 EXPERIMENT_DUAL_PRICE_AGREEMENT로 분리하며 API에는 연결하지 않았다.

결과: 복구 증가0. 기본 방식과 실험 모두 구매 개수98/141, 이름+개수72/122,
잘못 확정한 구매 개수0. 보조 복구 출처만 제외하면 나머지 정합 조건을 통과하는
후보는 고등어, 감자칩, 드레싱 세 행이었지만 모두 원본에 가격 하나만 검출되어
두 가격 일치 조건을 만족하지 못했다.

따라서 이 완화안은 운영에 채택하지 않는다. 단순히 보조 출처 허용 범위를
늘리면 해결된다는 가설은 현재 개발 자료에서 지지되지 않았다.
다음 실험은 이 세 행의 원본 숫자 영역을 대상으로 가격/수량 누락 복구를
평가하거나, 헤더·행 정렬과 보조 산식만으로 허용하는 대안의 오류율을 명시적으로
비교해야 한다. 두 방식 모두 이미 사용한 개발 자료이며 독립 성능 주장은 금지한다.

출력: `output/new_receipts/secondary_price_agreement.json`.

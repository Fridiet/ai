# 달걀 포장 내용량의 구 단위 처리

2026-09-12. IMG00059의 `안심신선란30구`를 달걀로 분류했지만 내용량을 1개로 기본 처리하는 문제를 확인했다. 달걀이라는 표준명과 원문의 명확한 달걀 상품 머리글이 모두 확인될 때만 끝의 양의 정수 `구`를 개수로 해석한다. 다른 제품·주소·계란찜·단위 없는 숫자에는 적용하지 않는다.

30구 한 포장은 30개, 검증된 구매 수량이 2이면 60개다. 구매 수량이 미확정이면 포장 내용량만 30개로 해석하고 `PURCHASE_QUANTITY_REQUIRES_CONFIRMATION` 안내를 유지한다. 30이라는 내용량을 구매 포장 수량으로 사용하지 않는다.

개발용 23장의 내용량 정답이 있는 23행 중 일치는 13→14행으로 늘었다. 그러나 구매 수량 근거까지 갖춘 내용량 일치는 조건부 보조 OCR에서 11/23으로 동일하다. 해당 달걀 구매 개수는 아직 미확정이므로 전체 등록 준비 개선 1건으로 주장하지 않는다. 이름·구매 수량 동시 정답 54/100과 구매 수량 정답 80/119도 그대로다.

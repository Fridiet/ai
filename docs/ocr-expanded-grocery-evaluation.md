# 신선식품 영수증 평가 확장

2026-09-12. 미검수 development 이미지에서 IMG00059와 IMG00664 원본을 시각 확인해 각각 19개, 9개 상품의 정답 초안을 추가했다. OCR 예측 명칭이 아닌 원본의 상품명·구매 수량을 기록했다. 포장 내용량이 명시된 경우 별도로 기록했고 아이스크림 브랜드 두 항목의 정규화 명칭은 null로 남겼다. 실제 사람이 검수한 정답으로 승격하지 않는다.

추가로 원본을 확인한 IMG00055/IMG00057은 주유, IMG00383은 교통카드 충전, IMG00770은 편의점 단일 크림샌드 구매로 시각 분류 목록에만 기록했다. 이 네 장을 정확도 분모에 추가하지 않았다. 미사용 평가 30장은 접근하지 않았다.

## 기본 OCR 캐시 재평가

- IMG00059: 이름 15/19, 구매 수량 13/19, 동시 정답 9/19.
- IMG00664: 식품 9행 모두 등록 후보에서 누락. 정규화 이름 정답을 정한 7행도 0/7.
- 확대된 23장 전체: 식품 119행, 이름 정답 있는 100행. 이름 71/100, 수량 64/119, 동시 정답 40/100, 잘못 확정된 수량 0.

이는 표본 확장이지 기존 성능 개선 또는 퇴보의 직접 비교가 아니다. 직전 21장 기본 정답은 이름 56/74·수량 51/91·동시 31/74였으며 보조 OCR 포함 수치와도 구분한다. 새 두 장의 보조 OCR는 아직 실행하지 않았다.

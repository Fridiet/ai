# 청파프리카 구체 명칭 보존 (2026-09-12)

원본 IMG00218의 `청파프리카 3개/1봉`이 일반 파프리카로 합쳐지는 문제를 수정했다.
사전에 청파프리카와 동의어 초록파프리카/녹색파프리카를 추가하고,
상위 분류 파프리카와 구체 품목 청파프리카를 구분했다.

- 실제 평가 결과: 청파프리카, 구매2봉, 재고6개, 이름/총량 모두 정답과 일치.
- 일반 파프리카 및 피망은 청파프리카로 추정하지 않는다.
- OCR 반환 분류 vegetable, 보관 방식은 기존 파프리카 규칙의 추정값을 사용한다.
- 동적 레시피 재료명 정규화도 청파프리카를 보존한다.
- 일반 파프리카 재고만으로 청파프리카 요구량을 충족했다고 처리하지 않는다.

개발25장(보조960 포함): 이름95→96/122, 이름+구매 개수71→72/122.
이름+총량20→21/37, 구매 개수98/141 및 총량24/37은 불변이다.
전체 pytest646개 통과. 이는 개발용 초안 평가이지 독립 정확도가 아니다.

기존 레시피 원문에도 청/홍/황파프리카가 있지만 저장된 레시피 데이터와
학습된 임베딩을 이번에 재생성하지 않았다. 따라서 레시피 전체와 DB까지
구체 품목 동기화가 완료됐다는 뜻은 아니다. 운영 서버도 재시작하지 않았다.
프론트/백엔드/DB/원격 저장소 변경 없음.

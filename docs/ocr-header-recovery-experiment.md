# 헤더 영역 재인식 실험

2026-09-12. 개발용 IMG00218의 원본 SHA 확인 후 상품 표 헤더 영역만 두 크기로 잘라 OCR을 실행했다. 여백 0.25배에서는 금액이 신뢰도 0.867로 인식됐고, 0.6배에서는 한 글자로 오인하여 실패했다. 원본에 없는 열 제목을 수동으로 만들지 않았다.

기존 상품명/단가/수량 헤더와 재인식 헤더의 위치를 검증한 뒤 누락된 열 제목 한 개만 추가하는 순수 함수를 만들었다. 기존 두 숫자 열 제목이 있어야 하며, 세 열 순서, 신뢰도 0.8, 동일 행 및 기존 열 좌표 일치를 확인한다. 기존 문자/좌표/수량은 덮어쓰지 않는다.

기본 OCR 캐시 분석과 헤더 보충 분석 비교에서 동일 영수증의 구매 수량 정답은 12→15개, 이름·수량 동시 정답은 10→13개였다. 이름 정답 19개와 단언한 구매 수량 오답 0은 유지됐다. 이는 기존 960 보조 OCR까지 포함한 전체 파이프라인 대비 추가 3개라는 뜻은 아니다. 전체 파이프라인 비교 및 다른 영수증 검증이 필요하다.

첫 좁은 영역 요청 10.214초에는 OCR 모델 로드가 포함됐다. 두 번째 넓은 영역 요청은 0.432초였으나 실패했다. 성공 경로의 웜 상태 지연은 아직 측정하지 않았다. 결과는 output/new_receipts/header_recovery_experiment.json에 저장됐다.

731개 테스트 통과. 현재 순수 병합 함수와 실험 스크립트만 추가했으며 운영 API에는 연결하지 않았다. 동결 평가 세트는 사용하지 않았다.

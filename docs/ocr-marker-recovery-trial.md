# 수량 보류 원인 분석: 금액 기호와 열 제목 누락

2026-09-12. 이름 정답이지만 구매 개수가 없는 24개 항목을 확인했다. 일부는 금액 기호, 일부는 숫자 자체의 충돌(7, 22 등), 일부는 가격/수량 검출 누락이었다.

단가/수량/금액 열이 검증된 경우에만 말미 % 또는 복수 기호를 허용하는 후보 규칙을 시험했다. 하지만 개발용 27장 집계에서 개선은 0이었다. 대상 IMG00218의 기본 검출은 상품명/단가/수량을 읽었으나 금액 열 제목이 누락되어 column anchors를 만들 수 없었다. 수량 승인 조건을 완화하는 것으로 해결할 문제가 아니므로 승인 규칙 변경은 철회했다.

기존 보조 OCR 행 대조에서는 %/*# 같은 기호가 붙으면 원문의 충돌하는 수량을 감지하지 못할 가능성이 있었다. 이를 감지하는 정규식 확장만 유지했다. 이 수정은 수량을 새로 승인하는 기능이 아니라 원문 7을 보조 OCR의 2로 덮어쓰지 않는 방어다. 4개 반례 테스트를 추가했다.

다음 후보는 누락된 열 제목/숫자 영역의 제한적 재인식이다. 원문 숫자 충돌을 가격 나눗셈으로 강제 수정하지 않는다. 이번 실험은 정확도 향상으로 계산하지 않는다.

# 우유 정체성과 손상된 내용량 단위 분리

2026-09-12. IMG00059의 `남양)1등급아침에우유 900m1*2입`이 미분류되고 있었다. 명시적 흰 우유 브랜드·수식어와 우유 중심어가 확인되는 제한된 경우에 `m1` 손상 단위가 상품 정체성을 가리지 않도록 했다. 정상 ml 표기는 기존 분류 경로를 그대로 유지한다. 딸기·초코·아몬드 우유, 우유 쿠키·샴푸는 이 규칙으로 일반 우유가 되지 않는다.

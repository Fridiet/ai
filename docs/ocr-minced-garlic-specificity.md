# 다진마늘 형태 보존

2026-09-12. 기존 마늘의 다진마늘/마늘다진것 별칭을 다진마늘 항목으로 이동했다. 형태가 명시되지 않은 마늘·통마늘은 기존 이름을 유지한다. 분류상 부모 마늘은 표시/카테고리용이며 재고를 자동 치환하는 근거가 아니다.

OCR과 team_recipe의 동적 이름 정규화에서 같은 이름으로 처리됨을 검사했다. 현재 저장된 레시피 JSON, DB ingredient_id 및 학습 모델을 다시 생성했다는 뜻은 아니다. 기존 데이터가 포괄적인 마늘로 저장돼 있다면 별도 원본 대조와 마이그레이션이 필요하다.

다진마늘에 원물 마늘의 실온 규칙을 상속하지 않는다. 명시된 냉동/냉장 텍스트가 있으면 적용하고, 없으면 UNKNOWN이다. 다진마늘소스·빵·샴푸 반례와 1kg 포장량 보존을 테스트했다. 이전 마늘로 축약하는 기대값 2개는 새로운 명세에 맞춰 수정했다. 사용자 제공 정답 초안은 수정하지 않았다.

개발용 27장 재평가에서 이름 정답 101→102/124, 이름·구매 개수 동시 정답 78/124 유지, 구매 개수 정답 102/143 유지, 단언한 구매 개수 오답 0. 724개 테스트 통과. 운영 서버·프론트/백엔드·DB·원격 저장소는 변경하지 않았다.

# 비식품 영수증의 불필요한 확인 항목

2026-09-12. 원본을 앞서 확인한 개발용 생활용품 영수증 IMG00024/27/34/65의 캐시를 학습 분류기 활성 상태에서 검사했다. 식품으로 확정된 항목은 네 장 모두 0개였지만, 대표자/사업자번호·POS 일시·문의전화·카드사 계좌 표시가 reviewCandidates에 들어갔다.

대표자 콜론, 대괄호 POS 필드, 정형 문의전화 머리말, 특정 은행/카드사명과 번호만 있는 행을 구조적으로 판별하는 receipt_metadata를 추가했다. 이름에 '대표', '은행' 등이 들어간 일반 상품을 광범위하게 제외하지 않는다. 사용자 개인정보는 문서에 다시 적지 않았다.

확인 후보는 수정 전 각각 11/6/5/5개에서 수정 후 6/1/1/0개로 줄었다. 제거한 19개는 상품이 아닌 부가정보다. 남은 생활용품은 식품으로 확정하지 않았지만, 학습 분류기가 비식품으로 확정하지 못한 경우 여전히 확인 후보가 된다. 이를 영수증 전체의 완벽한 비식품 필터라고 주장하지 않는다.

715개 회귀 테스트 통과. 식재료 은행, 대표사과 등의 단어만으로 metadata로 처리하지 않는 반례 포함. 동결 평가/DB/프론트/백엔드/운영 서버는 변경하지 않았다.

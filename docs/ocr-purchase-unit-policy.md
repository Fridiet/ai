# 구매 단위와 포장 내용량 안내 구분

2026-09-12. AI 응답의 수량/단위/저장 구조는 변경하지 않았다.

상품명에 내용량이 없고 숫자 조각도 없으며, 구매 수량이 VERIFIED_RECEIPT_COLUMNS 또는 VERIFIED_RECEIPT_TOTALS로 검증된 경우에는 `PURCHASE_UNIT_COUNT_ONLY` 안내를 사용한다. 반환 `개`는 영수증 구매 단위를 의미하며 봉지 안의 낱개 수가 아니다. 무게·용량으로 관리할 때만 변경하도록 안내한다. 포장 내용량을 추정해 만들지 않는다.

900m1, 숫자만 남은 용량, 수량 기본값, 가격 역산 및 보조 OCR 복구 항목에는 기존 확인 경고를 유지한다. 보관 방식·날짜·이름 불확실성 안내도 그대로다.

개발용 25장 캐시 재평가에서 16개 항목의 포장량 경고가 구매 단위 설명으로 바뀌었다. 이름·개수 정답 74/122, 물리적 재고량 정답 24/37은 변하지 않았다. 하나 이상의 수량/보관 확인 경고가 있는 반환 식품은 103→93개, 이름·개수 정답 중 해당 경고가 있는 항목은 66→57개다. 이는 확인 안내 정책 변경이지 인식 정확도 향상이 아니다. 소비기한 입력과 보관 추천까지 포함한 무확인 등록률로 해석하지 않는다.

현재 운영 서버에 이 변경을 활성화하지 않았다. 프론트/백엔드, DB, 원격 저장소는 변경하지 않았다.

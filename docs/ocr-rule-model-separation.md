# 학습 분류기 스위치와 기본 정규화 분리

2026-09-12. 이전에는 OCR_CLASSIFIER_ENABLED=false일 때 apply_classification이 즉시 원래 사전 매칭을 반환해 상품 전체 이름 보정과 복합상품 오분류 방지도 생략됐다. true로 평가한 결과가 기본 설정의 실행과 달라지는 원인이었다.

이제 비식품, 완전한 상품 종류명, 원재료 접미사, 복합상품 충돌 규칙은 항상 적용한다. 모델 로딩/예측만 기존 플래그로 제어한다. 모델을 끄거나 로딩에 실패해도 사전/규칙 경로를 사용할 수 있다. 기존 모델 파일이나 학습 가중치는 변경하지 않았다.

모델 비활성화 테스트에서 친환경복주머니양파→양파, 송송어린대파→대파, 레몬녹차/또르띠아/멸균우유 등을 확인했다. 샤인머스켓음료와 멸균우유초콜릿은 원료로 단언하지 않고, 초코마시멜로쿠키는 쿠키로 유지한다. disabled 경로에서 모델 loader 호출 시 테스트가 실패하도록 검증했다.

학습 모델을 사용한 평가와 꺼진 평가의 전체 성능이 같다는 의미는 아니다. 캐시 비교 보고서에 classifier_enabled와 정답 파일 SHA를 기록하도록 보완했다. 단일 환경의 테스트 통과는 모든 미지 상품에 대한 증명이 아니며 개발/동결 평가 구분은 유지한다. 운영 서버를 재시작하지 않았다.

# 실제 숫자 재인식 및 확인 부담 감사

2026-09-12. 개발용 수동 시각 검수 초안 25장만 사용. 동결 평가 30장은 사용하지 않았다. 주 OCR 및 960 검출은 기존 캐시, 숫자 영역 인식은 원본 SHA를 확인한 실제 이미지에서 실행했다. 따라서 전체 HTTP 지연 평가가 아니며, 캐시 생성 단계의 오염 배제나 독립 정확도도 증명하지 않는다.

구매 개수 기준 이름/수량 수정 필요 비율은 48/122(39.3%)지만 날짜·보관·포장량을 포함하지 않는다. 반환되지 않은 식품은 30/141(21.3%)이며, 모두 OCR 문자 누락이라는 뜻은 아니다. 분류 보류와 이름 미확정 등을 포함한다. 이 수치를 OCR 검출 누락률로 표시하면 안 된다.

확인 경고 집계는 CONFIRMATION, 수량 기본값, 가격 역산 경고를 포함하며 중복 경고가 있다. 포장량 확인 74건, 보관 미확정 63건, 구매 개수 미확정 27건이다. 이름·개수가 맞고 이 경고가 없는 8건에도 보관 추천 및 소비기한 입력 관련 상태가 남는다. 따라서 8/122도 완전 자동 등록률이 아니다. 소비기한 정답 라벨 자체가 없어 그 정확도를 측정하지 못한다.

다음 우선순위는 포장 개수로 등록 가능한 경우와 실제 분량 입력이 필요한 경우의 확인 정책을 구분하고, 상품 고유명이 확실한데 사전에 없어 보류되는 경우를 개선하는 것이다. 단순히 경고를 삭제하거나 임의 소비기한을 정답으로 취급하지 않는다.

## 2026-09-12 후속: 맛 표현의 부분 일치

사워크림·바닐라·초콜릿·치즈·케첩·마요네즈가 긴 상품명의 일부에만 일치하면 사전 일치만으로 확정하지 않도록 했다. 원문 전체의 명확한 상품 종류 또는 추가 분류 근거를 요구한다. 단품명+포장 크기는 유지하고 독립 검증된 정확한 상품 카탈로그 매칭도 기존 우선순위를 유지한다. 이는 감자칩으로의 퍼지 자동 보정 규칙이 아니다.

중간 검증에서 정상 카라멜초콜릿이 보류되는 부작용을 발견했다. 명확한 카라멜초콜릿 상품명은 완성된 상품 종류로 인정하고, 임의의 알 수 없는 앞부분까지 함께 인정하지 않는 회귀 테스트를 추가했다.

최종 27장 혼합 재생: 정확한 이름 104/124, 이름·구매 개수 일치 82/124 유지. 잘못된 이름 확정 4→3, 분류 보류 15→16. IMG00376의 `김자침사워크림`을 사워크림으로 잘못 확정하던 경로가 보류로 바뀌었다. **자동 처리율 상승이 아니라 잘못된 등록 방지 개선**이다. 올바른 감자칩으로 자동 복원하는 과제는 남아 있다.

전체 테스트 763개 통과. 중간 변경 시 기존 98장 점검은 이전 집계와 동일했고, 최종 초콜릿 보완은 테스트 및 27장으로 검증했다. 98장 전체를 최종 코드로 재실행했다고 해석하지 않는다. 운영 서버/DB/프론트/백엔드는 변경하지 않았다.

## 로컬 API 반영 (2026-09-12 후속)

이전 문단의 서버 미반영 상태를 다음과 같이 갱신했다. 8011 임시 서버에서 4장×2회 요청이 모두 200이며 이미지별 응답 해시가 동일했다. 반복 4회 지연은 4.09~9.65초(표본 중앙값 6.13초); 최초 IMG00218 요청은 16.79초다. 이 작은 직렬 표본을 서비스 전체 지연 SLA로 간주하지 않는다.

`verify_receipt_runtime`으로 백오이 5개, 감자칩 110g, 김자침사워크림의 확인 대상 분리, 레이즈 감자칩 분류를 실제 HTTP 응답에서 검사했다. 검증한 특정 항목만 통과했다는 의미이며 해당 영수증 전체가 정확하다는 뜻은 아니다.

로컬 AI `.env`에 보조 수량·숫자 셀·헤더 재인식 3개 옵션을 활성화했다. 8000 포트가 비어 있음을 확인한 후 현재 코드로 `--env-file .env`를 지정해 서버를 시작했다. 이후 동일한 실제 이미지 의미 검증 4건이 8000에서도 통과했다. 8011 임시 서버는 종료했다. DB 생성은 실행 환경에서 비활성화했고 분석 API만 호출했으며 DB 데이터, 프론트/백엔드는 수정하지 않았다.

결과: `output/receipt_readiness/api_flavor_heads_20260912.json`, `http_semantics_8011.json`, `http_semantics_8000.json`. `.env`는 커밋하지 않는다. 재실행 명령은 README에 명시했다. 아직 남은 미분류·세부 품목·수량 오류 및 독립 평가 검증은 계속 필요하다.

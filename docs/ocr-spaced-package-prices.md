# 공백 포함 용량을 가격으로 잘못 읽는 문제 수정

2026-09-12. 레몬녹차(340 ml)의 340이 가격 정규식에 잡혀 상품명이 `레몬녹차(`에서 잘리고 재고 용량이 유실됐다. 가격 후보를 찾을 때 명시적인 단위 표기의 숫자 범위를 제외한다. 정규화에서도 단위를 가격보다 먼저 제거해 `ml` 잔여 토큰이 남지 않도록 했다. 원본 OCR 텍스트는 바꾸지 않았다.

레몬녹차를 레몬 원물과 분리해 사전에 추가하고, 또르띠아/토르띠아/또르티야를 또띠아 표기 변형으로 등록했다. 단순 숫자 500은 여전히 가격일 수 있으며, 단위가 깨진 숫자를 용량으로 추측하지 않는다.

개발 27장 캐시 평가: 표준명 101/124, 구매 개수 102/143, 이름·구매 개수 동시 78/124, 물리적 재고량 25/38. 단언한 구매 수량 오답 0. 새 영수증 응답 생성 결과 레몬녹차340ml, 또띠아2개. 이 수치는 초안 정답/개발용이며 독립 정확도나 무확인 자동 등록률이 아니다.

692개 단위/회귀 테스트와 이전 영수증 98장 캐시 평가를 실행했다. 이전 98장 보고서: output/receipt_readiness/after-spaced-package-prices.json. 원래 25장과 새 27장은 분모가 다르므로 백분율을 그대로 비교하지 않는다. 숫자 셀은 기존 25장 캐시가 있는 항목에만 적용됐다.

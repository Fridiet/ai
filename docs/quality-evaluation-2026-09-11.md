# 품질 평가와 부족 수량 계산

## 실제 영수증 회귀 평가

`evaluation/market_receipt_v1.json`은 제공된 이미지에서 전사한 상품 32행·할인 5행 정답 초안이다.
식품 30행(가공품 포함), 비식품 2행이다. 다른 사람의 2차 검수가 필요하다.
사전 수정에 이미 사용한 이미지이므로 **개발 회귀용**이며 독립 테스트셋이 아니다.
식재료명은 일부 넓은 표준명(버섯 등)을 허용한다. 세분류 정확도를 평가하는 지표가 아니다.
원본 이미지/원시 OCR은 Git에 추가하지 않고, 평가 시 로컬 스냅샷을 사용한다.

실행: AI 폴더에서 `python -m scripts.evaluate_market_receipt`.
먼저 `scripts.audit_ocr_output --image <경로>`로 생성한 `output/ocr_audit.json`이 있어야 한다.
결과는 `output/market_receipt_evaluation.json`에 행별 오차, 정답/원본 해시와 함께 저장된다.

| 지표 | 결과 |
|---|---|
| 식품 선별 Precision | 20/20 = 100% |
| 식품 선별 Recall | 20/30 = 66.67% |
| 표준명+구매 개수 종단간 Recall | 20/30 = 66.67% |
| 용량·단위 종단간 Recall | 9/14 = 64.29% |

분모에는 누락된 정답 행도 포함한다. 단위가 이미지에서 확실하지 않으면 용량 정답을 만들지 않는다.
텍스트 유사도로 행을 1:1 정렬하므로 정렬 오류와 인식 오류를 구분해 확인해야 한다.
양상추→약삼축은 육안 확인 후 정렬용 별칭만 지정했으며 정답 표준명은 양상추로 유지했다.
현재 미추출에는 크랩킹, 국물떡볶이, 이슬송이버섯, 국탕용 어묵, 대파, 콩나물, 톳, 백숙,
250g 다진마늘, 오리엔탈 드레싱이 포함된다. 이 결과는 일반 영수증 정확도로 발표하면 안 된다.

## 개인화 추천: 이력에 없는 메뉴 평가

실행: `python -m scripts.evaluate_personalization_holdout`.
DB에 쓰지 않는다. 고정 날짜·같은 재고·같은 건강 설정으로 비교하며, 합성 취향 3종별로
메뉴 하나를 취향 이력에서 빼고 나머지 메뉴의 12일 조리 기록만 입력한다.
이력에 넣었던 메뉴가 다시 높은 순위로 나오는 자기 확인 평가를 피하기 위한 별도 실험이다.
단, 제외 메뉴도 원래 Two-Tower 학습 데이터에 포함됐을 수 있으므로 모델의 완전 미지 레시피 평가는 아니다.
961개 전체 후보의 벡터 검색 순위이며 최종 재고·건강 제약 적용 후 앱 추천 순위가 아니다.

| 가정한 정답 메뉴 | 이력 없음 순위 | 개인화 순위 |
|---|---:|---:|
| 된장 두부국 | 321 | 203 |
| 소고기 버섯볶음 | 239 | 194 |
| 새우 브로콜리볶음 | 613 | 518 |

세 메뉴 모두 순위는 올랐지만 Precision/Recall/NDCG @1,5,10,20은 모두 0이었다.
신규 사용자의 빈 이력 결과는 기본 추천과 동일했다.
합성 사용자 3명/각 정답 1개뿐이며 **실제 사용자 선호 정확도 수치가 아니다**.
평가 결과를 좋게 만들기 위한 모델 가중치 변경·재학습은 이번 단계에서 하지 않았다.

다음 추천 개선 실험은 별도의 검증/테스트 취향 시나리오를 먼저 고정하고,
현재 방식과 재료·조리법 특징 기반 취향 결합을 비교한다. 가중치는 검증셋에서만 결정하고
테스트 결과는 마지막에 한 번 보고한다. 실제 저장·조리 기록은 동의를 받아 합성 데이터와 구분한다.

## 장바구니 수량 계산

필요량에서 호환 단위의 보유량만 뺀다. 당근 500g 필요, 보유 0.2kg → 300g 부족.
모르는 포장 크기·재료별 개당 무게·밀도는 추측하지 않고 UNKNOWN으로 전달한다.
소비기한 만료/0 재고가 이름만 있는 구버전 필드로 되살아나는 문제도 수정했다.
DB 스키마 변경 없이 AI 응답 → Spring DTO → 장바구니 UI에 추가 필드로 연결했다.

검증: AI 97개, Spring 25개 테스트, 프론트 타입 검사 통과.
4개 합성 계정의 Spring→AI 장보기 응답 및 피드백 미기록/타 냉장고 접근 거부 재확인.
커밋·푸시는 하지 않았다.

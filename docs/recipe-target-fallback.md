# 지정 재료 추천의 대체 처리

`/api/recipes/ai`는 지정 재료를 포함하는 안전한 후보가 있으면 기존처럼 해당 후보만 추천한다.
후보가 없지만 현재 재고로 추천 가능한 다른 실제 레시피가 있으면 이를 반환하고
`reasons`에 **요청 재료 활용 추천이 아닌 대체 추천**임을 명시한다.

소비기한 제외, 제외 재료, 주재료 보유 조건은 완화하지 않는다. 없는 재고를 생성하거나
레시피 원본·학습 모델·DB를 변경하지 않는다. 모든 안전한 후보가 없으면 기존 404를 유지한다.
쇼핑 모드의 추가 구매 개수 조건도 유지한다.

원인: 프론트 자동 추천이 소비기한 지난 재고까지 지정 재료로 요청하고,
조건에 맞는 후보가 없는 경우의 404도 개발 환경에서 오류 화면으로 표시한다.
이 변경은 AI 내부의 명시적 대체 정책이다. 모든 404 또는 프론트 오류 표시 자체를 없애지는 않는다.

복구: `app/main.py`의 `allow_target_fallback=True`를 `False`로 바꾸고 AI를 재시작하면
지정 재료 필수 정책으로 복귀한다. 외부 응답 필드와 기존 엄격 모드 함수 동작은 유지한다.
